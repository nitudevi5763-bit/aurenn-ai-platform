# Aurenn AI — AI Intake & Lead Operations

Central admin + client dashboard for Aurenn AI's chatbot clients.

## What's built so far

- /login — shared login for admin and clients, redirects based on role
- /admin — admin-only: list of clients
- /dashboard — client-only: their own leads

## Environment variables

See .env.example. Add the real values in Vercel -> Project Settings -> Environment Variables.
